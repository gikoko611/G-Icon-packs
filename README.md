# G.I KO KO Royal Gold Icon Pack

Android icon pack with bright gold 3D Burmese floral filigree frames and a one-tap Apply action for supported launchers.

Target: Android 10+ compatible project; Redmi 9A / ARMv7 build compatibility will be checked in CI.

**Important:** Android does not let a normal app replace every launcher icon globally. One-tap apply works only for launchers that support the icon-pack protocol; MIUI stock launcher may require a compatible launcher or manual per-app shortcuts.
